# UNI CARE — University Clinic Recording Application

## Intelligent Web-Based University Clinic Operations and Decision Support System

UNI CARE is an Intelligent Web-Based University Clinic Operations and Decision Support System designed to improve fragmented and manual university clinic workflows through centralized student records, digital check-in, queue management, clinic services, dental appointments, inventory transactions, feedback collection, operational reports, and decision-support capabilities.

This repository contains the **initial Java-based Recording Application** developed as the foundation of the proposed UNI CARE system.

The current implementation focuses on a **console-based user interface**, **Object-Oriented Programming (OOP)**, and a **file-based database using `.txt` files**. It is intended to establish the system's initial classes, records, business operations, and data persistence before the proposed system is expanded into a web-based platform with a relational database, RFID integration, analytics, and AI-assisted decision support.

# 1. Project Overview

University clinic operations involve several interconnected activities, including student identification, check-in, queue management, clinic consultations, dental appointments, medicine and supply transactions, feedback, and reporting.

When these activities depend heavily on manual encoding, separate records, spreadsheets, and disconnected workflows, clinic personnel may experience difficulties such as:

- Repetitive manual data entry
- Fragmented clinic workflows
- Inefficient student flow
- Difficulty managing queues
- Appointment processing difficulties
- Manual medicine and supply transactions
- Spreadsheet-based inventory management
- Difficulty monitoring physical inventory
- Disconnected feedback collection
- Limited operational reporting
- Limited visibility into clinic workload and waiting times

UNI CARE proposes a centralized platform that connects these operational areas into one system.
